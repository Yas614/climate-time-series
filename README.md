# Climate series

## Overview
This project analyzes historical climate data for 5 African countries:
Ethiopia, Kenya, Sudan, Tanzania, and Nigeria.

## Objectives
- Clean and preprocess climate data
- Perform exploratory data analysis (EDA)
- Identify trends, patterns, and anomalies

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- notebooks/: contains EDA notebooks for each country
- data/: cleaned datasets (not included in repo)

## How to Run
1. Clone the repository
2. Install requirements:
   pip install -r requirements.txt
3. Open notebooks using Jupyter

## Key Tasks Completed
- Data cleaning (-999 handling, missing values)
- Time series analysis
- Correlation analysis
- Visualization and insights
